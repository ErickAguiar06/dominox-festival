# Dominox Festival — Manual do Jogo
Site estático (index.html). Publicado via GitHub Pages.

1. Crie o repositório `dominox-festival` no GitHub e envie estes arquivos (branch `main`).
2. Settings > Pages > Source: **GitHub Actions**.
3. Aguarde o workflow terminar. Link: https://SEU-USUARIO.github.io/dominox-festival/
4. `pip install qrcode[pil]` e `python make_qr.py <link>` gera o QR code.
